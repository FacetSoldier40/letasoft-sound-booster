## 🎯 Overview

**Letasoft Sound Booster** is a Windows utility that increases the **volume of any audio** playing on your PC — well beyond the standard 100% limit imposed by Windows. Whether your speakers are too quiet, a video has weak audio, or a call is hard to hear, Sound Booster can amplify it up to **500%** without requiring new hardware.

It works system-wide by inserting a virtual audio processing layer between your applications and your output device.

### 🎯 Why Use It?

| Problem | Solution |
|---------|----------|
| 🔊 Speakers too quiet | Boost up to 500% |
| 🎬 Movie audio is soft | Per-app boosting |
| 🎧 Headphone volume limited | System-wide amplification |
| 📞 Quiet video calls | Boost in real-time |
| 🎮 In-game audio too low | Game-specific profile |
| 🎵 Music sounding flat | Volume + EQ |

## 💡 How It Works

```
┌──────────────────────────────────────────────┐
│  Application (Browser, Player, Game)         │
│              │                               │
│              ▼                               │
│  Windows Audio Session                       │
│              │                               │
│              ▼                               │
│  ┌────────────────────────────────┐          │
│  │   Letasoft Sound Booster       │          │
│  │   (Amplification Engine)       │          │
│  └────────────────────────────────┘          │
│              │                               │
│              ▼                               │
│  Output Device (Speakers / Headphones)       │
└──────────────────────────────────────────────┘
```

The booster intercepts the audio stream, amplifies it via a DSP (digital signal processor), applies limiter protection, and sends the result to your output device.

## 🔊 Audio Quality

### ⚠️ Avoiding Distortion

High boost levels can cause clipping. Follow these rules:

| Boost Level | Risk | Recommendation |
|:-----------:|:----:|----------------|
| 100–200% | Low | Safe |
| 200–300% | Medium | Watch for crackle |
| 300–400% | High | Lower source volume |
| 400–500% | Very High | Only for desperate cases |

### 🎛️ Equalizer Tips

| Frequency | Adjustment | Effect |
|-----------|-----------|--------|
| 60 Hz | -2 dB | Reduce muddiness |
| 250 Hz | 0 dB | Neutral |
| 1 kHz | +1 dB | Presence |
| 4 kHz | +2 dB | Clarity |
| 10 kHz | +1 dB | Air |

### 🎚️ Limiter Settings

Enable the limiter at high boost levels to prevent hard clipping:

- 🛡️ **Soft Limit**: Musical compression
- 🎯 **Hard Limit**: Strict ceiling
- 🎛️ **Threshold**: -1 dB recommended

## 💬 FAQ

**Is Sound Booster free?**
It has a free trial; full version is paid.

**Does it damage speakers?**
Not if used within safe limits. High boost can strain small speakers.

**Can it boost microphone input?**
No — output audio only.

**Does it work with Bluetooth?**
Yes, but quality depends on the codec.

**Is it safe for headphones?**
Yes — but avoid prolonged high-volume listening.

**Can I use it with a DAC?**
Yes — DAC processes the boosted signal.

**Does it slow my PC?**
Minimal impact — under 1% CPU.

**Can I disable it temporarily?**
Yes — via pause button or hotkey.

**Will it work in games?**
Yes — it processes the audio session.

**Can I uninstall cleanly?**
Yes — via Control Panel → Programs.
